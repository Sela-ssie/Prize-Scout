# Starter watchlist

starting source list, not an endorsement or a list of currently open offers.
The original eight channel IDs and upload playlists were resolved through
`channels.list` on 2026-10-14. Aquarium Co-Op and Andertons were added on
2026-10-15 after official-source research and API identity resolution. The
personal `watchlist.json` remains ignored by Git and Docker.

categories come from extracted item names. Some creators direct entries to other
sites or have geographic, age, purchase, or membership restrictions; always read
the official rules. This app does not enter promotions or establish eligibility.

no mentions. This is a low-yield discovery result, not evidence that the channels
never run giveaways. See [discovery notes](../docs/SOURCE_DISCOVERY.md) for identity
provenance, standing-rule limitations and provisional leads.
